# เปลี่ยน Haven Valley เป็นเกม 2D — แผนงาน

> สถานะ: **อนุมัติแล้ว** (31 ต.ค. 2026) · P1-2D เสร็จแล้ว
> งาน 3D ทั้งหมด (Phase 0–2C) เก็บไว้ใน branch `prototype-3d` บน GitHub ไม่หายไปไหน

## 1. สิ่งที่เลือกแล้ว

| เรื่อง | ทางเลือก |
|---|---|
| มุมมอง | มุมบนเอียงเล็กน้อย (top-down 3/4) แบบ Stardew Valley |
| สไตล์ภาพ | Pixel art, tile 16 × 16 px |
| ขนาดโลก | โลกเดียวต่อเนื่อง **320 × 320 tile** (1 tile ≈ 3.125 ม. ของแบบแปลนเดิม) ทุกภูมิภาคอยู่ตำแหน่งเดิม |
| ภาพ | แอสเซ็ตฟรี CC0 ก่อน แล้วค่อยเปลี่ยนเป็นภาพจริงทีหลัง |
| Engine | Godot 4.7.2 (2D) ภาษา GDScript เหมือนเดิม |

## 2. แอสเซ็ตที่ต้องดาวน์โหลด (ผมดาวน์โหลดเองไม่ได้)

| ชุด | ใช้ทำอะไร | สัญญาอนุญาต | ลิงก์ |
|---|---|---|---|
| **Ninja Adventure** (หลัก) | ตัวละคร 45+ ตัวพร้อมแอนิเมชันเดิน, tileset พื้น/บ้าน/ธรรมชาติ, ไอเท็ม 30+, UI | CC0 | https://pixel-boy.itch.io/ninja-adventure-asset-pack |
| Kenney Tiny Town (เสริม) | บ้าน/รั้ว/ต้นไม้เพิ่ม ถ้าชุดหลักไม่พอ | CC0 | https://kenney.nl/assets/tiny-town |

วางไฟล์ zip (หรือโฟลเดอร์ที่แตกแล้ว) ไว้ที่ `HavenValley/art_source/packs/` — โฟลเดอร์นี้ Godot ไม่นำเข้า ผมจะเขียนเครื่องมือคัดเฉพาะภาพที่ใช้เข้า `assets/`

ใช้ Ninja Adventure เป็นหลัก เพราะการผสมหลายชุดทำให้โทนสีไม่เข้ากัน ชุดนี้ **ไม่มีพืชผลการเกษตร** — ผมจะวาด placeholder พืช 3 ชนิดให้เข้ากับโทนสีของชุด (Phase 3B)

## 3. ตั้งค่าภาพ pixel art

- ความละเอียดเกม 480 × 270 ขยายเป็นจำนวนเต็มเท่า (×4 = 1920 × 1080) ภาพคมไม่เบลอ
- `rendering/textures/canvas_textures/default_texture_filter = Nearest`, stretch mode `viewport`, aspect `keep`
- กล้อง Camera2D ตามผู้เล่นแบบนุ่ม ล็อกขอบแผนที่
- Y-sort ให้ตัวละครเดินหลังต้นไม้/บ้านได้ถูกต้อง

## 4. แปลงโลกจากแบบแปลนเดิมเป็น tile

ใช้ `world_layout.json` และข้อมูลจาก Phase 2A ต่อ:

| ข้อมูลเดิม | กลายเป็น |
|---|---|
| พิกัดสถานที่ 53 แห่ง | ตำแหน่ง tile = (x + 500) ÷ 3.125 |
| ความสูงภูมิประเทศ | **ขั้นหน้าผา (terrace)** แบบ Stardew: ระดับความสูงแบ่งเป็นชั้น มีหน้าผาคั่น ทางขึ้นเป็นบันได/ทางลาด |
| แผนที่ชนิดพื้น (ถนนดิน หินปูถนน ดินไถ ทราย) | tile พื้นแบบ autotile (terrain set ของ Godot) |
| แม่น้ำ ลำธาร ทะเลสาบ | tile น้ำตื้น/น้ำลึก มีขอบตลิ่ง, น้ำลึกเดินไม่ได้ |
| ถนน + สะพาน 8 แห่ง | tile ถนน + สะพานไม้ข้ามน้ำ |
| ต้นไม้/หิน (NatureScatter) | ต้นไม้/หินเป็น sprite วางด้วยกฎเดิม (หลบถนน น้ำ อาคาร) |
| อาคาร | sprite บ้านจากชุดแอสเซ็ต วางตาม footprint (ปัดเป็น tile) |

เครื่องมือ `tools/map/build_tilemap.gd` สร้างแผนที่จากข้อมูลเหล่านี้ทุกครั้งที่แบบแปลนเปลี่ยน เหมือน Phase 2

## 5. อะไรใช้ต่อได้ / อะไรเลิกใช้

**ใช้ต่อ (ปรับเล็กน้อย)**
- `world_layout.json`, เอกสารแบบแปลน, ชื่อภูมิภาค
- EventBus, GameManager, เมนูหลัก, เมนูหยุด, HUD (UI เป็น 2D อยู่แล้ว)
- ระบบไอเท็ม (`ItemData`, `ItemRegistry`), กระเป๋า (`Inventory`), `WorldState` (ID ถาวร) — ที่เริ่มทำใน 3A
- ระบบโต้ตอบ (เปลี่ยน Area3D → Area2D), รูปแบบการทดสอบอัตโนมัติ
- ข้อมูล heightmap / control / zone map (ใช้สร้าง tile)

**เลิกใช้ (ยังอยู่ใน branch `prototype-3d`)**
- Terrain3D, ภูมิประเทศ 3D, water shader 3D, โมเดล Blender, ตัวละคร/กล้อง 3D
- Blender ไม่อยู่ในขั้นตอนงานแล้ว — ภาพ pixel art แก้ด้วย Aseprite / LibreSprite (ฟรี) หรือโปรแกรมที่คุณถนัด

## 6. Roadmap ใหม่

| Phase | เนื้อหา | หมายเหตุ |
|---|---|---|
| **P1-2D Foundation** | ตั้งค่า pixel-perfect, ผู้เล่นเดิน 4 ทิศ + แอนิเมชัน, วิ่ง, กล้อง, ระบบโต้ตอบ Area2D, HUD/เมนูเดิม, ทดสอบอัตโนมัติ | ทำใหม่จาก Phase 1 |
| **P2-2D World** | สร้าง tilemap 320×320 จากแบบแปลน: พื้น ถนน น้ำ หน้าผา สะพาน อาคาร ต้นไม้ หิน ชื่อภูมิภาค; ทดสอบว่าเดินถึงทุกสถานที่ (ค้นทางบน grid) | ทำใหม่จาก Phase 2 |
| **P3 Gameplay** | 3A ไอเท็ม/กระเป๋า/Hotbar/ตัดไม้ ทุบหิน เก็บของป่า · 3B ฟาร์มพืช 3 ชนิด · 3C ก่อสร้างบน grid | เหมือนเดิม (บน grid 2D ทำง่ายขึ้น) |
| P4–P8 | การใช้ชีวิต, ขยายโลก, ระบบโลก, ขัดเกลา, อนาคต | เหมือนเดิม |

ประมาณงาน: P1-2D และ P2-2D รวมแล้วน้อยกว่า Phase 1–2 แบบ 3D เพราะไม่มีภูมิประเทศ 3D และโมเดล
