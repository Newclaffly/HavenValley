# Phase 2 — ต้นแบบโลก (World Prototype)

Phase 2 แบ่งเป็น 3 ส่วน เพื่อให้แต่ละส่วนทดสอบได้จบในตัว

| ส่วน | เนื้อหา | สถานะ |
|---|---|---|
| **2A** | ภูมิประเทศจริงจากแบบแปลน, แม่น้ำ/ลำธาร/ทะเลสาบ/น้ำตก, ถนนตามความชัน, สะพานเดินข้ามได้, ท่าเรือ, ชื่อภูมิภาค, ทดสอบ Terrain3D | ✅ เสร็จ (ทดสอบผ่าน 18/18) |
| **2B** | เชื่อม Terrain3D: นำ heightmap เข้า Terrain3D, ปั้นและระบายพื้นใน editor, เท็กซ์เจอร์พื้นแบบการ์ตูน | ⬜ รอคุณติดตั้ง Terrain3D (ดูข้อ 3) |
| **2C** | โมเดลอาคาร blockout จาก Blender (W5), ต้นไม้และหินชุดแรกตามภาพอ้างอิง | ⬜ |

## 1. สิ่งที่ได้ใน 2A

- **ภูมิประเทศ 1 × 1 กม. ตามแผนความสูง** — เทือกเขาทางเหนือสูงสุด ~160 ม., ป่า Westwood ไต่ขึ้นไปทางตะวันตก, ที่ราบหมู่บ้าน Y 10 (ย่านที่พัก Y 11), ฟาร์มราบ Y 8, ทุ่งหญ้าลอนคลื่นทางใต้ และเนินกังหันลม
- **สถานที่สำคัญทั้งหมดอยู่ที่ความสูงตามแบบแปลนพอดี** (ผิดพลาด 0.00 ม.) แต่ละจุดมีลานราบของตัวเอง
- **แม่น้ำ Haven** ไหลจากต้นน้ำ 110 ม. → น้ำตก Highfall (ตก 18 ม.) → โรงสี → ทะเลสาบ Mirror, **ลำธาร Willow** ผ่านน้ำตก Willow → ข้างฟาร์ม → ทุ่งหญ้า, **ทางน้ำออก** จากทะเลสาบลงทางใต้ ทุกสายมีร่องน้ำจริงและตลิ่ง
- **ทะเลสาบ Mirror** ลึก 8 ม. ตรงกลาง มีชายตื้น 1.2 ม. ให้ลุยน้ำได้ เกาะ Willow ตรงกลาง
- **Water shader** สีเทอร์ควอยซ์ เข้มขึ้นตามความลึก ขอบฟองขาวตรงที่น้ำแตะพื้น (ตามภาพอ้างอิง) น้ำไหลตามทิศแม่น้ำ น้ำตกเป็นฟองขาว
- **ถนนทุกสายตัดตามความชันที่กำหนด** (ถนนในหมู่บ้าน 3%, ถนนหลัก 8%, ทางเล็ก 10%, ทางเดิน 15%, เส้นทางภูเขา 30%) ทาสีดิน/หินปูถนนลงบนพื้น
- **สะพาน 8 แห่งเดินข้ามได้** พื้นสะพานลาดจากตลิ่งหนึ่งไปอีกตลิ่ง มีราวกั้น · **ท่าเรือ 2 แห่ง** ที่ทะเลสาบ
- **ชื่อภูมิภาค** ขึ้นกลางจอเมื่อเดินเข้า (หมู่บ้าน, ฟาร์ม, ป่า, ภูเขา, แม่น้ำ, ทะเลสาบ, ทุ่งหญ้า)
- **ระบบกันตกน้ำลึก** เดินลงทะเลสาบส่วนลึกแล้วจะถูกพากลับขึ้นฝั่งพร้อมข้อความ (ว่ายน้ำมาใน Phase 5) ตกนอกโลกก็กลับจุดปลอดภัยล่าสุด
- **F3** แสดงด้วยว่าอยู่บนพื้นหรือลอยอยู่

## 2. ผลทดสอบ Terrain3D กับ Godot 4.7.2 ✅

ผมคอมไพล์ Terrain3D **v1.0.2** จากซอร์สโค้ดแล้วทดสอบกับ Godot 4.7.2

| ทดสอบ | ผล |
|---|---|
| โหลด GDExtension และลงทะเบียนคลาส | ผ่าน (`Terrain3D version 1.0.2`) |
| นำเข้า `heightmap.exr` ของ Haven Valley (1025 × 1025) | ผ่าน ใช้เวลา 70 ms ได้ 25 region (256 ม.) |
| ความสูงที่ได้ เทียบกับแบบแปลน | ตรงทุกจุด: ศาลากลาง 10.00 · ฟาร์ม 8.00 · เหมือง 50.00 · ก้นทะเลสาบ −8.00 · ยอดเขา 96.00 |
| บันทึกข้อมูล region และรันต่อหลายเฟรม | ผ่าน ไม่มี error |
| คำเตือน | มีแค่ `instance_reset_physics_interpolation() is deprecated` จากภายใน Terrain3D ไม่มีผลต่อการทำงาน |

**สรุป: ใช้ Terrain3D v1.0.2 กับ Godot 4.7.2 ได้**

## 3. ติดตั้ง Terrain3D (ทำครั้งเดียว ก่อนเริ่ม 2B)

ผมส่งไฟล์ .dll สำหรับ Windows ให้จากที่นี่ไม่ได้ เพราะดาวน์โหลดไฟล์ release ไม่ได้และคอมไพล์ข้ามเป็น Windows ไม่ได้ ติดตั้งจากใน Godot ได้แบบนี้:

1. เปิดโปรเจกต์ใน Godot 4.7.2 → แท็บ **AssetLib** ด้านบน
2. ค้นหา **Terrain3D** → เปิด → **Download**
3. ในหน้าต่าง Install ให้ติ๊กเฉพาะโฟลเดอร์ `addons/terrain_3d` → **Install**
4. **Project → Project Settings → Plugins** → เปิด **Terrain3D**
5. ปิดแล้วเปิด Godot ใหม่ (Project → Reload Current Project)

ถ้าใน AssetLib ไม่ใช่เวอร์ชัน 1.0.2 บอกผมเลขเวอร์ชันด้วย (ดูได้ที่ `addons/terrain_3d/plugin.cfg`)

เกมยังเล่นได้ปกติไม่ว่าจะติดตั้งแล้วหรือยัง เพราะภูมิประเทศใน 2A ใช้ระบบในตัวของ Godot

## 4. สถาปัตยกรรม

```
แบบแปลน (world_layout.json)
   │
   ├─► tools/terrain/generate_terrain.py ──► heightmap (raw) + control.png + zones.png + preview
   │        (Python: numpy, scipy, Pillow)          │
   │                                                 ▼
   │   tools/terrain/build_terrain_resources.gd ──► heightmap.res (เกมใช้) + heightmap.exr (Terrain3D/Blender)
   │
   └─► ในเกม
        Terrain  (HeightmapTerrain)  heightmap.res → 64 tile mesh + HeightMapShape3D + get_height()
        Water    (WaterBuilder)      river/creek/outflow profile → ribbon mesh + ทะเลสาบ
        Greybox  (GreyboxBuilder)    อาคาร ป้าย สะพาน ท่าเรือ วางบนความสูงจาก Terrain
        World    (WorldManager)      จุดเกิด, chunk, region, กันตกน้ำลึก
```

การตัดสินใจทางเทคนิค
- **Heightmap สร้างจากแบบแปลนด้วยสคริปต์** ไม่ได้ปั้นมือ จึงสร้างใหม่ได้ทุกครั้งที่แก้แบบแปลน และทุกอย่างตรงกัน: ร่องแม่น้ำในพื้นกับผิวน้ำใช้ profile เดียวกัน, ถนนใช้เส้นเดียวกับที่ NPC จะใช้
- **ขั้นตอนสร้างพื้น** ภูมิประเทศธรรมชาติ → ลานราบ (ฟาร์ม หมู่บ้าน และลานใต้สถานที่สำคัญทุกแห่ง) → ขุดร่องแม่น้ำ/ลำธาร/ทะเลสาบ → ปรับถนนให้อยู่ในความชันที่กำหนด (ยึดความสูงกับลานและถนนที่ตัดผ่าน) → ปรับถนนรอบสุดท้ายบนพื้นที่เสร็จแล้ว
- **Python ใช้สร้าง heightmap** เพราะต้องคำนวณ 1 ล้านจุดหลายรอบ (8 วินาทีใน Python, หลายนาทีใน GDScript) ไฟล์ที่ได้อยู่ในโปรเจกต์แล้ว ไม่ต้องติดตั้ง Python ถ้าไม่แก้แบบแปลน
- **ภูมิประเทศในตัว Godot ก่อน Terrain3D** เกมเล่นได้ทันทีโดยไม่พึ่ง add-on และทดสอบอัตโนมัติได้ทั้งหมด Terrain3D จะใช้สำหรับปั้นและระบายใน editor ใน 2B
- **Region ตรวจด้วยโค้ด** (`WorldLayout.region_at`) แทน Area3D: รูปทรงอยู่ใน JSON ไม่ต้องใช้ physics, ทดสอบได้ง่าย, ใช้ซ้ำกับแผนที่ในเกมได้

## 9. วิธีทดสอบ

ทดสอบด้วยตัวเอง (F5 → New Game)
1. เกิดในฟาร์ม ชื่อ **Farm Valley** ขึ้นกลางจอ มองเห็นภูเขาด้านหลังหมู่บ้าน
2. วิ่งไปศาลากลางตามถนน (~45 วินาที) → ชื่อ **Haven Village** ขึ้น
3. เดินถนนสายตะวันตกข้ามสะพานป่า (B4) → เดินบนสะพานได้ ไม่ตกลงลำธาร → **Westwood Forest**
4. เดินถนนสายเหนือขึ้นทางคดเคี้ยวถึงเหมืองทองแดงเก่า (ความสูง 50 ม.)
5. ถนนโรงสีไปทางตะวันออกเฉียงเหนือ → ข้ามสะพานโรงสี → เส้นทางขึ้นไปดูน้ำตก Highfall
6. ถนนสายตะวันออกไปท่าเรือริมทะเลสาบ → เดินบนท่าเรือ → ลุยน้ำตื้นได้ → เดินลงส่วนลึก = ถูกพากลับฝั่งพร้อมข้อความ
7. F3 → ดูพิกัด ความสูง และ "on ground"

ทดสอบอัตโนมัติ (F6 ที่ฉาก): `tests/phase1_test.tscn` 27 ข้อ · `tests/phase2_test.tscn` 18 ข้อ ได้แก่ ความสูงสถานที่ · ความชันถนนทุกสาย · ทะเลสาบลึกและชายตื้น · มองเห็นหอศาลากลางจากฟาร์ม ท่าเรือ และจุดเริ่มเส้นทาง · วิ่งฟาร์ม→ศาลากลาง · เดินขึ้นทางคดเคี้ยวถึงเหมือง · ข้ามสะพานไม่ตกน้ำ · ชื่อภูมิภาค · กันตกน้ำลึก

**แก้แบบแปลนแล้วสร้างพื้นใหม่** (ต้องมี Python 3.10+, numpy, scipy, Pillow)
```
python tools/terrain/generate_terrain.py
godot --headless --path . -s res://tools/terrain/build_terrain_resources.gd
```

## 11. ข้อจำกัดที่รู้อยู่แล้ว

- ภาพทดสอบของผมเรนเดอร์ด้วยซอฟต์แวร์ สีจึงซีดและหินดูขาวเกินจริง บนการ์ดจอของคุณ (Forward+) น่าจะต่างออกไป ถ้าสีแปลก ส่งภาพหน้าจอมาได้
- ขอบถนนบนพื้นยังเบลอเมื่อมองใกล้ (แผนที่ชนิดพื้นละเอียด 1 ม./พิกเซล) จะคมขึ้นเมื่อใช้เท็กซ์เจอร์ Terrain3D ใน 2B
- อาคารยังเป็นกล่อง ต้นไม้และหินยังไม่มี (2C)
- น้ำยังไม่มีการว่ายน้ำ ไม่มีเสียงน้ำ ไม่มีละอองน้ำตก (Phase 5 / 7)
- ทางลาดถนนตรงโค้งหักศอกและจุดที่ถนนต่อกับลาน อาจชันกว่ากำหนดเล็กน้อยในช่วง 2 ม. (ทดสอบยอมให้ไม่เกิน 1.5 เท่าของค่าที่กำหนด) ช่วง 10 ม. อยู่ในเกณฑ์ทั้งหมด
