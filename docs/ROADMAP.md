# Haven Valley — Roadmap การพัฒนา

เกมจำลองชีวิตแบบโลกเปิด 2D (Cozy Life Simulation)

> **31 ต.ค. 2026: เปลี่ยนเป็นเกม 2D** (ดู [`PIVOT_2D.md`](PIVOT_2D.md)) — งาน 3D Phase 1–2C เก็บไว้ใน branch `prototype-3d`
เอนจิน **Godot 4.7.2** · ภาษา **GDScript** · **2D isometric ภาพเวกเตอร์การ์ตูน (tile 128 × 64 px)** · โค้ด **github.com/Newclaffly/HavenValley**

เอกสารนี้คือแผนหลักของโปรเจกต์ ทุกเฟสมี "เป้าหมาย", "งาน" และ "เกณฑ์ผ่าน" (สิ่งที่ต้องทดสอบได้จริงก่อนปิดเฟส)
สถานะล่าสุดของแต่ละงานอยู่ใน [`CHECKLIST.md`](CHECKLIST.md)

กฎการทำงาน
- ทำทีละเฟส และ **รอการอนุมัติก่อนเริ่มเฟสหลักถัดไป**
- ก่อนแก้ไฟล์: ตรวจโปรเจกต์ปัจจุบัน → เข้าใจสถาปัตยกรรม → ระบุ dependency → วางแผน → แจ้งไฟล์ที่จะเปลี่ยน
- ทุกฟีเจอร์ต้องมี: ออกแบบ, สถาปัตยกรรม, สคริปต์ครบ, path ไฟล์, โครงสร้างฉาก, การตั้งค่า Inspector, signal, วิธีทดสอบ และอัปเดตเอกสาร
- ไม่ทำฟังก์ชันหลอกแล้วบอกว่าเสร็จ ใช้ API ของ Godot 4.x ที่มีจริงเท่านั้น และทดสอบด้วย Godot 4.7.2 ก่อนส่งทุกครั้ง
- ทุกส่วนงานที่เสร็จ commit ลง GitHub `Newclaffly/HavenValley`

ข้อมูลอ้างอิงหลัก
- แบบแปลนแผนที่โลก: `resources/world/world_layout.json` (1000 × 1000 ม., chunk 125 ม., +X ตะวันออก, −Z เหนือ)
- แผนที่ 2D: 320 × 320 tile, 1 tile = 16 px = 3.125 ม. ของแบบแปลน, ทิศเหนืออยู่ด้านบนจอ
- จุดเกิดผู้เล่น: (−152, 8, 182) ในฟาร์ม · ศาลากลาง: (0, 10, −24)

## Phase 0 — แบบแปลน ✅ เสร็จแล้ว

**เป้าหมาย** ออกแบบโลกให้สร้างจริงได้ก่อนเขียนโค้ด

- แผนที่มุมบน ระบบพิกัด ตาราง chunk 8 × 8
- ภูมิภาค: หมู่บ้าน Haven (กลาง), ฟาร์ม (ตะวันตกเฉียงใต้), ป่า Westwood (ตะวันตก), เทือกเขา Ridge (เหนือ), แม่น้ำ Haven และทะเลสาบ Mirror (ตะวันออก), ทุ่งหญ้า Meadowlands (ใต้)
- ตารางพิกัดสถานที่ 53 แห่ง, แผนความสูง, ถนน 5 ประเภท, สะพาน 8 แห่ง, พื้นที่ก่อสร้างและพื้นที่ขยาย
- กลยุทธ์ภูมิประเทศใน Godot, รายการแอสเซ็ต Blender, ขั้นตอนสร้างโลก W1–W9

**การตัดสินใจ** Godot 4.7.2 · ฟาร์มทางตะวันตกเฉียงใต้ · โปรเจกต์อยู่ที่ `Documents\HavenValley` · (เดิม Terrain3D, เปลี่ยนเป็น 2D 31 ต.ค. 2026)

## P1-2D — รากฐาน 2D (Foundation) ✅ เสร็จ

**เป้าหมาย** เกม 2D ที่เปิดได้ เดินสำรวจแผนที่ greybox ทั้งโลกได้ และโต้ตอบกับวัตถุได้

- ✅ ตั้งค่า pixel art: Compatibility renderer, texture filter Nearest, กล้องซูม ×4 (เห็นโลก 480 × 270 px บนจอ 1080p), snap 2D
- ✅ ผู้เล่น CharacterBody2D เดิน 8 ทิศ หันหน้า 4 ทิศ วิ่ง แอนิเมชันจาก sprite sheet (`CharacterSprite`)
- ✅ ระบบโต้ตอบ Area2D (`Interactable`, `InteractionDetector`, `InfoSign`)
- ✅ แผนที่ greybox 320 × 320 tile จากแบบแปลน: หญ้า ถนน แม่น้ำ ลำธาร ทะเลสาบ สะพาน อาคาร ป้ายทุกสถานที่
- ✅ ชื่อภูมิภาค, chunk, กล้องไม่ออกนอกแผนที่, เมนูหลัก/หยุด/HUD เดิม
- ✅ ทดสอบ `tests/p1_2d_test.tscn` 25/25
- ✅ **เปลี่ยนเป็น isometric เวกเตอร์:** ระบบภาพวาดด้วยโค้ด (`tools/art/iso_art.py`), พื้นเวกเตอร์, อาคาร 26 หลัง, ต้นไม้/พุ่มไม้/หิน/ดอกไม้ทั้งแผนที่, ตัวละคร 4 ทิศ — ทดสอบ 34/34

## P2-2D — โลก (World) ⬜

**เป้าหมาย** แผนที่จริงแทน greybox

- ภูเขาเป็นชั้นหน้าผา (terrace) มีบันได/ทางลาด จากข้อมูลความสูงเดิม
- น้ำเคลื่อนไหว ฟองตามขอบ น้ำตก, รอยต่อถนน-ลานเนียนขึ้น
- ภาพเฉพาะของแต่ละอาคาร (โรงนา เรือนกระจก โรงสี บ่อน้ำ) แผงตลาด รั้ว
- เข้าอาคารได้ (ฉากภายในแบบห้อง isometric)
- **เกณฑ์ผ่าน** ค้นทางบน grid แล้วเดินถึงทุกสถานที่ได้ · ไม่มีต้นไม้/หินบนถนนหรือในน้ำ · ทุกอาคารมีประตูเข้าถึงได้

## Phase 3 — ระบบเกมพื้นฐาน (Gameplay Foundation) ⬜

**เป้าหมาย** เก็บของ ปลูกพืช และสร้างบ้านหลังเล็กได้

- ✅ 3A ไอเท็ม 7 ชนิด, กระเป๋า 24 ช่อง, Hotbar 8 ช่อง, ตัดไม้ ทุบหิน เก็บเห็ด/เบอร์รี่/ดอกไม้ (ID ถาวรใน `WorldState`, งอกใหม่) — ทดสอบ 35/35 ([`P3A.md`](P3A.md))
- 3B ฟาร์ม: ไถดิน ปลูก รดน้ำ ระยะเติบโต เก็บเกี่ยว — พืช 3 ชนิด
- 3C ก่อสร้างบน grid tile: ฐาน พื้น ผนัง ประตู หน้าต่าง หลังคา, หมุน, ตรวจพื้นที่, ค่าวัสดุ, รื้อถอน

**เกณฑ์ผ่าน** เก็บไม้และหิน → ปลูก รดน้ำ เก็บเกี่ยวพืชครบ 3 ชนิด → สร้างบ้านเล็กบนแปลง A ได้
