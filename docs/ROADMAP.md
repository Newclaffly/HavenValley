# Haven Valley — Roadmap การพัฒนา

เกมจำลองชีวิตแบบโลกเปิด (Cozy Open-World Life Simulation)
เอนจิน **Godot 4.7.2** · ภาษา **GDScript** · โมเดล **Blender (glTF/GLB)** · ภูมิประเทศ **Terrain3D 1.1.0** · โค้ด **github.com/Newclaffly/HavenValley**

เอกสารนี้คือแผนหลักของโปรเจกต์ ทุกเฟสมี "เป้าหมาย", "งาน" และ "เกณฑ์ผ่าน" (สิ่งที่ต้องทดสอบได้จริงก่อนปิดเฟส)
สถานะล่าสุดของแต่ละงานอยู่ใน [`CHECKLIST.md`](CHECKLIST.md)

กฎการทำงาน
- ทำทีละเฟส และ **รอการอนุมัติก่อนเริ่มเฟสหลักถัดไป**
- ก่อนแก้ไฟล์: ตรวจโปรเจกต์ปัจจุบัน → เข้าใจสถาปัตยกรรม → ระบุ dependency → วางแผน → แจ้งไฟล์ที่จะเปลี่ยน
- ทุกฟีเจอร์ต้องมี: ออกแบบ, สถาปัตยกรรม, สคริปต์ครบ, path ไฟล์, โครงสร้างฉาก, การตั้งค่า Inspector, signal, วิธีทดสอบ และอัปเดตเอกสาร
- ไม่ทำฟังก์ชันหลอกแล้วบอกว่าเสร็จ ใช้ API ของ Godot 4.x ที่มีจริงเท่านั้น และทดสอบด้วย Godot 4.7.2 ก่อนส่งทุกครั้ง
- ทุกส่วนงานที่เสร็จ commit ลง GitHub `Newclaffly/HavenValley` พร้อม tag ของเฟส (เช่น `phase-2b`)

ข้อมูลอ้างอิงหลัก
- แบบแปลนแผนที่โลก: `resources/world/world_layout.json` (1000 × 1000 ม., chunk 125 ม., +X ตะวันออก, −Z เหนือ, 1 หน่วย = 1 ม.)
- จุดเกิดผู้เล่น: (−152, 8, 182) ในฟาร์ม · ศาลากลาง: (0, 10, −24)

## Phase 0 — แบบแปลน ✅ เสร็จแล้ว

**เป้าหมาย** ออกแบบโลกให้สร้างจริงได้ก่อนเขียนโค้ด

- แผนที่มุมบน ระบบพิกัด ตาราง chunk 8 × 8
- ภูมิภาค: หมู่บ้าน Haven (กลาง), ฟาร์ม (ตะวันตกเฉียงใต้), ป่า Westwood (ตะวันตก), เทือกเขา Ridge (เหนือ), แม่น้ำ Haven และทะเลสาบ Mirror (ตะวันออก), ทุ่งหญ้า Meadowlands (ใต้)
- ตารางพิกัดสถานที่ 53 แห่ง, แผนความสูง, ถนน 5 ประเภท, สะพาน 8 แห่ง, พื้นที่ก่อสร้างและพื้นที่ขยาย
- กลยุทธ์ภูมิประเทศใน Godot, รายการแอสเซ็ต Blender, ขั้นตอนสร้างโลก W1–W9

**การตัดสินใจ** Terrain3D · Godot 4.7.2 · ฟาร์มทางตะวันตกเฉียงใต้ · โปรเจกต์อยู่ที่ `Documents\HavenValley`

## Phase 1 — รากฐาน (Foundation) ✅ เสร็จแล้ว

**เป้าหมาย** โปรเจกต์ที่เปิดได้ เดินสำรวจโลก greybox ได้ และกดโต้ตอบกับวัตถุได้

งาน
- สร้างโปรเจกต์ Godot 4.7.2 และโครงสร้างโฟลเดอร์ตาม Master Prompt
- Autoload: `EventBus` (ศูนย์กลาง signal), `GameManager` (สถานะเกม, เปลี่ยนฉาก, หยุดเกม)
- เมนูหลัก (New Game / Continue / Quit) และเมนูหยุดเกม (ESC)
- ตัวควบคุมผู้เล่นมุมมองบุคคลที่สาม: เดิน วิ่ง กระโดด หันตามทิศเดิน
- กล้อง: หมุนด้วยเมาส์, ซูมด้วยล้อเมาส์, กล้องไม่ทะลุกำแพง (SpringArm3D), เคลื่อนไหวลื่นด้วย physics interpolation
- สภาพแวดล้อมเริ่มต้น: โลก greybox สร้างอัตโนมัติจาก `world_layout.json` (W1 ในแบบแปลน)
- ระบบโต้ตอบ: คอมโพเนนต์ `Interactable`, ตัวตรวจจับหน้าผู้เล่น, ข้อความ "[E] …" บนหน้าจอ, ป้ายบอกทางทุกสถานที่
- HUD: ข้อความโต้ตอบ, การแจ้งเตือน, ข้อมูลดีบัก (F3: FPS, พิกัด, chunk)
- ฉากทดสอบอัตโนมัติ `tests/phase1_test.tscn`

**เกณฑ์ผ่าน**
- กด New Game แล้วเกิดในฟาร์ม หันหน้าไปทางหมู่บ้าน
- เดิน / วิ่ง / กระโดด / หมุนกล้องได้ลื่น กล้องไม่ทะลุอาคาร
- วิ่งจากฟาร์มถึงศาลากลางได้ในประมาณ 45 วินาที
- เดินไปหาป้ายแล้วเห็น "[E] Read sign" กด E แล้วเห็นชื่อสถานที่และพิกัด
- ESC หยุดเกมได้ กลับเมนูหลักได้
- ฉากทดสอบอัตโนมัติผ่านทุกข้อ

## Phase 2 — ต้นแบบโลก (World Prototype) ✅ เสร็จ

**เป้าหมาย** เปลี่ยนโลก greybox แบนให้เป็นภูมิประเทศจริงตามแบบแปลน รายละเอียดใน [`PHASE2.md`](PHASE2.md)

**2A — ภูมิประเทศและน้ำ ✅**
- ✅ ทดสอบ Terrain3D v1.0.2 กับ Godot 4.7.2 (ผ่าน)
- ✅ Heightmap 1025 × 1025 สร้างจากแบบแปลน (W2) + ภูมิประเทศในตัว Godot พร้อม collision
- ✅ แม่น้ำ ลำธาร ทางน้ำออก ทะเลสาบ น้ำตก + water shader (W3)
- ✅ ถนนตามความชันที่กำหนด ทาสีลงพื้น, สะพาน 8 แห่ง และท่าเรือ 2 แห่งเดินได้ (W4)
- ✅ ชื่อภูมิภาค, กันตกน้ำลึก

**2B — Terrain3D ✅**
- ✅ Terrain3D 1.1.0 ในโปรเจกต์, ข้อมูลภูมิประเทศจาก heightmap, shader สไตล์ Haven Valley
- ✅ ฉากปั้นพื้นใน editor, ภูมิประเทศสำรองอัตโนมัติเมื่อไม่มี Terrain3D

**2C — แอสเซ็ตชุดแรก ✅**
- ✅ Blockout อาคารหมู่บ้านและฟาร์ม 15 หลัง + บ้าน 3 แบบ + แผงตลาด 3 แบบ จาก Blender (W5) ขนาดตาม footprint ในแบบแปลน
- ✅ ต้นสน โอ๊ก เบิร์ช พุ่มไม้ หิน (11 แบบ) วางอัตโนมัติตามภูมิภาค ~3,200 ต้น หลบถนน น้ำ และอาคาร

**เกณฑ์ผ่าน** ไม่มีถนนชันเกินกำหนด ✅ · น้ำไหลลงเนินทุกจุด ✅ · มองเห็นหอศาลากลางจากฟาร์มและท่าเรือ ✅ · เดินถึงทุกสถานที่โดยไม่ต้องกระโดด ✅ (ทดสอบเส้นทางหลัก)

## Phase 3 — ระบบเกมพื้นฐาน (Gameplay Foundation)

**เป้าหมาย** เก็บของ ปลูกพืช และสร้างบ้านหลังเล็กได้

งาน
- ระบบไอเท็มแบบ Resource (`ItemData`), กระเป๋า (Inventory) และ Hotbar
- เก็บทรัพยากร: ตัดต้นไม้ ทุบหิน เก็บของป่า (ของที่เก็บได้มี ID ถาวร)
- ระบบฟาร์ม: เตรียมดิน ปลูก รดน้ำ ระยะการเติบโต เก็บเกี่ยว — พืช 3 ชนิด
- ระบบก่อสร้างพื้นฐาน: ฐาน พื้น ผนัง ประตู หน้าต่าง หลังคา, กริด 1 ม. + snap, หมุน, ตรวจพื้นที่ก่อสร้าง, ค่าวัสดุ, รื้อถอน (W6)

**เกณฑ์ผ่าน** เก็บไม้และหิน → ปลูก รดน้ำ เก็บเกี่ยวพืชครบ 3 ชนิด → สร้างบ้านเล็กบนแปลง A ได้

## Phase 4 — การใช้ชีวิต (Life Simulation)

**เป้าหมาย** หมู่บ้านมีชีวิต ซื้อขายได้ เลี้ยงสัตว์ได้

งาน
- NPC: ชื่อ บุคลิก บ้าน งาน ตารางชีวิตประจำวัน (NavigationAgent3D)
- บทสนทนาและความสัมพันธ์ (ค่าความสนิท)
- ร้านค้าและเศรษฐกิจ (Gold): ซื้อเมล็ด ขายผลผลิต
- สัตว์: ไก่ วัว แกะ หมู แพะ — ให้อาหาร ความสุข เก็บผลผลิต ที่อยู่สัตว์
- งานคราฟต์: สูตรแบบ Resource ตั้งค่าได้, โต๊ะช่าง

**เกณฑ์ผ่าน** คุยกับ NPC ได้ · ซื้อเมล็ดและขายพืชได้ · เลี้ยงไก่และเก็บไข่ได้ · คราฟต์เครื่องมือได้

## Phase 5 — ขยายโลก (World Expansion)

**เป้าหมาย** ทุกภูมิภาคในแบบแปลนสร้างเสร็จและน่าสำรวจ

งาน
- ป่า Westwood เต็มรูปแบบ, เทือกเขา, ทะเลสาบ, ถ้ำและเหมือง (เดินเข้าได้ ไม่มีหน้าจอโหลด)
- อาคารหมู่บ้านที่เหลือ, สัตว์ป่า, ตกปลา, ขุดแร่, สถานที่ลับและของสะสม
- กระจายพืชพรรณต่อ chunk + ID ถาวร (W7), งานภาพพื้นที่ MVP (W8)

**เกณฑ์ผ่าน** ทุกสถานที่ในตารางพิกัดมีอยู่จริงในเกม · ตกปลาและขุดแร่ได้

## Phase 6 — ระบบโลก (World Systems)

**เป้าหมาย** เวลาเดินไป ฤดูเปลี่ยน และเซฟเกมได้

งาน
- `TimeManager`: กลางวัน/กลางคืน (รุ่งเช้า เช้า บ่าย เย็น กลางคืน)
- สภาพอากาศ: แดด เมฆ ฝน พายุ หมอก
- ฤดูกาล: ใบไม้ผลิ ร้อน ใบไม้ร่วง หนาว — มีผลต่อพืช NPC สัตว์ แสง เสียง
- `SaveManager`: หลายช่องเซฟ, เวอร์ชันเซฟ, เขียนไฟล์อย่างปลอดภัย, migration, เก็บเฉพาะสิ่งที่เปลี่ยนจากโลกต้นฉบับ
- ความก้าวหน้า (Progression) และการปลดล็อก

**เกณฑ์ผ่าน** เซฟ → ปิดเกม → เปิดใหม่ → ทุกอย่างอยู่ที่เดิม (ตำแหน่ง ของ เงิน อาคาร พืช สัตว์ ความสัมพันธ์ เวลา อากาศ)

**= จบ MVP ตามข้อ 14 ของ Master Prompt**

## Phase 7 — ขัดเกลา (Polish)

- UI ทุกหน้าจอ (กระเป๋า สถานะ ก่อสร้าง คราฟต์ ร้านค้า แผนที่ ตั้งค่า เซฟ/โหลด) ในธีมเดียวกัน
- เสียง ดนตรี แอนิเมชันตัวละคร
- ปรับประสิทธิภาพตามงบ: 60 fps ที่ 1080p บน GTX 1060 / RX 580 (W9)
- แก้บั๊ก, รองรับภาษาไทย/อังกฤษ, ทดสอบการใช้งาน

## Phase 8 — ฟีเจอร์อนาคต

- เล่นร่วมกัน (Co-op): ฟาร์มร่วม สร้างร่วม เยี่ยมฟาร์ม แลกเปลี่ยน ความเป็นเจ้าของ
- ระบบก่อสร้างขั้นสูง, NPC เพิ่ม, ภูมิภาคใหม่ (X6–X9 ในแบบแปลน), กิจกรรมเพิ่ม

สถาปัตยกรรมเตรียมไว้ตั้งแต่ตอนนี้: ระบบเกมแยกจาก UI และ input ของผู้เล่นท้องถิ่น, สถานะโลกใช้ ID ถาวร
