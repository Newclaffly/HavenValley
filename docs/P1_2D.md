# P1-2D — รากฐาน 2D

เกม 2D ที่เปิดได้ เดินสำรวจแผนที่ greybox ทั้งโลก 320 × 320 tile ได้ และโต้ตอบกับป้ายได้
ภาพตัวละครและ tile ยังเป็นภาพชั่วคราว (`tools/art/make_placeholders.py`) จนกว่าจะนำเข้าชุด Ninja Adventure ใน P2-2D

## 1. การตั้งค่าโปรเจกต์ (`project.godot`)

| ค่า | ตั้งเป็น | เหตุผล |
|---|---|---|
| `rendering/renderer/rendering_method` | `gl_compatibility` | เกม 2D ไม่ต้องใช้ Forward+, ทำงานได้กับการ์ดจอทุกรุ่น |
| `rendering/textures/canvas_textures/default_texture_filter` | Nearest (0) | pixel art คม ไม่เบลอ |
| `rendering/2d/snap/snap_2d_transforms_to_pixel` | เปิด | ภาพไม่สั่นเมื่อกล้องเลื่อน |
| `display/window/stretch` | `canvas_items` / `expand`, ฐาน 1920 × 1080 | UI เดิมใช้ได้ทันที ตัวหนังสือคม |
| กล้องผู้เล่น `zoom` | ×4 | เห็นโลก 480 × 270 px (30 × 17 tile) |
| `physics/common/physics_interpolation` | เปิด | เคลื่อนที่ลื่นแม้ FPS ไม่ตรง physics |
| Layer 2D | 1 world · 2 player · 3 interactable · 4 npc | เหมือนเดิม |
| Input ใหม่ | `use_tool` (คลิกซ้าย, F), `inventory` (Tab, I), `hotbar_1`–`hotbar_8` (1–8) | จองไว้ให้ Phase 3 |

## 2. หน่วยและพิกัด

- แบบแปลนเป็นเมตร: +X ตะวันออก, +Z ใต้ (เหนือ = −Z)
- แผนที่ 2D: 320 × 320 tile, **1 tile = 16 px = 3.125 ม.**, มุมบนซ้ายของแผนที่ = (0, 0) px = แบบแปลน (−500, −500)
- `WorldLayout.to_pixels(x, z)` เมตร → px · `WorldLayout.to_metres(px)` px → เมตร (Vector3 x, 0, z) · `WorldLayout.to_tile(px)` px → tile
- ความเร็วผู้เล่นเป็น tile/วินาที (เดิน 5, วิ่ง 8) ข้ามแผนที่ทั้งหมด ~64 วินาทีเมื่อเดิน, ~40 วินาทีเมื่อวิ่ง

## 3. ไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `scripts/player/player_controller.gd` | `PlayerController` (CharacterBody2D): เดิน 8 ทิศ หัน 4 ทิศ วิ่ง |
| `scripts/player/character_sprite.gd` | `CharacterSprite` (AnimatedSprite2D): สร้างแอนิเมชันจาก sprite sheet |
| `scripts/interaction/interactable.gd` | `Interactable` (Area2D, layer 3) |
| `scripts/interaction/interaction_detector.gd` | `InteractionDetector`: เลือกของที่ใกล้และอยู่ด้านหน้า, กด E |
| `scripts/interaction/info_sign.gd` | `InfoSign`: ป้ายอ่านได้ |
| `scripts/world/world_manager.gd` | `WorldManager`: วาดแผนที่ greybox จากแบบแปลน, ป้าย, จุดเกิด, ภูมิภาค/chunk |
| `scripts/world/world_layout.gd` | อ่านแบบแปลน + แปลงหน่วย |
| `scenes/player/player.tscn` · `scenes/world/world.tscn` | ฉากผู้เล่นและโลก |
| `resources/tiles/placeholder_tileset.tres` | TileSet ชั่วคราว 4 tile (หญ้า ทาง น้ำ ผนัง) — น้ำและผนังมี collision |
| `assets/placeholder/*.png` · `tools/art/make_placeholders.py` | ภาพชั่วคราวและสคริปต์ที่วาด |
| `tests/p1_2d_test.tscn` | ทดสอบ 25 ข้อ |

ใช้ต่อจากเดิม: `EventBus`, `GameManager` (เมาส์ไม่ถูกล็อกแล้ว), เมนูหลัก, เมนูหยุด, HUD (แสดง tile/ทิศแทนตำแหน่ง 3D)

## 4. โครงสร้างฉาก

```
World (Node2D, WorldManager, y_sort)
├─ Ground (TileMapLayer, z_index −10)       แผนที่ greybox 320 × 320
├─ Signs (Node2D, y_sort)                    InfoSign ของทุกสถานที่
├─ Player (player.tscn)
│  ├─ Feet (CollisionShape2D 10 × 6 ที่เท้า)
│  ├─ Sprite (CharacterSprite)
│  ├─ Facing (Node2D หมุนตามทิศที่หัน, +Y ชี้ไปข้างหน้า)
│  │  └─ InteractionDetector (Area2D) └─ Reach (วงกลม r 10 px ห่าง 10 px ด้านหน้า)
│  └─ Camera (Camera2D zoom ×4, smoothing, physics process)
├─ WorldEdges (StaticBody2D) กำแพงล่องหน 4 ด้าน
├─ HUD · PauseMenu
```

## 5. Inspector

**Player (PlayerController)** — Walk Tiles Per Second 5 · Run Tiles Per Second 8 · Acceleration 60 · Deceleration 80
**Sprite (CharacterSprite)** — Sheet (sprite sheet: 1 คอลัมน์ต่อทิศ ลำดับ ลง ขึ้น ซ้าย ขวา, 1 แถวต่อเฟรมเดิน) · Frame Size 16 × 16 · Walk Frames 4 · Walk Fps 8
**InteractionDetector** — Facing Weight 12 (px ที่การหันหน้าชนะระยะใกล้)

แอนิเมชันถูกสร้างตอนรัน: `idle_down/up/left/right`, `walk_down/up/left/right` (วิ่งเล่นเร็วขึ้น 1.5 เท่า)

## 6. Signal

| Signal | ใครส่ง | ใครฟัง |
|---|---|---|
| `EventBus.interaction_target_changed(prompt)` | InteractionDetector | HUD (แถบ "[E] …") |
| `EventBus.interacted(target, interactor)` | Interactable | ระบบที่สนใจ (ภายหลัง) |
| `EventBus.notification_requested(title, message)` | InfoSign และอื่นๆ | HUD |
| `EventBus.player_chunk_changed(chunk)` | WorldManager | HUD (ดีบัก) |
| `EventBus.region_changed(id, name)` | WorldManager | HUD (ป้ายชื่อภูมิภาค) |
| `EventBus.game_paused(paused)` | GameManager | PauseMenu |

## 8. ข้อจำกัด (แก้ใน P2-2D)

- แผนที่ยังเป็น greybox: tile 4 แบบ ไม่มีขอบ autotile ไม่มีความสูง/หน้าผา ไม่มีต้นไม้
- อาคารเป็นบล็อกผนังเต็ม footprint ยังไม่มีประตู
- ภาพตัวละครชั่วคราว — ตัวโหลด sprite sheet ออกแบบตามรูปแบบ "Walk.png" ของ Ninja Adventure (คอลัมน์ = ทิศ, แถว = เฟรม) จะตรวจกับไฟล์จริงตอนนำเข้า
