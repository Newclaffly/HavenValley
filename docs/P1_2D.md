# P1-2D — รากฐาน 2D

เกม 2D ที่เปิดได้ เดินสำรวจแผนที่ greybox ทั้งโลก 320 × 320 tile ได้ และโต้ตอบกับป้ายได้
ภาพตัวละครและ tile ยังเป็นภาพชั่วคราว (`tools/art/make_placeholders.py`) จนกว่าจะนำเข้าชุด Ninja Adventure ใน P2-2D

## 1. การตั้งค่าโปรเจกต์ (`project.godot`)

| ค่า | ตั้งเป็น | เหตุผล |
|---|---|---|
| `rendering/renderer/rendering_method` | `gl_compatibility` | เกม 2D ไม่ต้องใช้ Forward+, ทำงานได้กับการ์ดจอทุกรุ่น |
| `rendering/textures/canvas_textures/default_texture_filter` | Nearest (0) | pixel art คม ไม่เบลอ |
| `rendering/2d/snap/snap_2d_transforms_to_pixel` | เปิด | ภาพไม่สั่นเมื่อกล้องเลื่อน |
| `display/window/stretch` | `canvas_items` / `expand`, ฐาน 1920 × 1080 | UI เดิมใช้ได้ทันที ตัวหนังสือคม |
| กล้องผู้เล่น `zoom` | ×4 | เห็นโลก 480 × 270 px (30 × 17 tile) |
| `physics/common/physics_interpolation` | เปิด | เคลื่อนที่ลื่นแม้ FPS ไม่ตรง physics |
| Layer 2D | 1 world · 2 player · 3 interactable · 4 npc | เหมือนเดิม |
| Input ใหม่ | `use_tool` (คลิกซ้าย, F), `inventory` (Tab, I), `hotbar_1`–`hotbar_8` (1–8) | จองไว้ให้ Phase 3 |

## 2. หน่วยและพิกัด

- แบบแปลนเป็นเมตร: +X ตะวันออก, +Z ใต้ (เหนือ = −Z)
- แผนที่ 2D: 320 × 320 tile, **1 tile = 16 px = 3.125 ม.**, มุมบนซ้ายของแผนที่ = (0, 0) px = แบบแปลน (−500, −500)
- `WorldLayout.to_pixels(x, z)` เมตร → px · `WorldLayout.to_metres(px)` px → เมตร (Vector3 x, 0, z) · `WorldLayout.to_tile(px)` px → tile
- ความเร็วผู้เล่นเป็น tile/วินาที (เดิน 5, วิ่ง 8) ข้ามแผนที่ทั้งหมด ~64 วินาทีเมื่อเดิน, ~40 วินาทีเมื่อวิ่ง

## 4. โครงสร้างฉาก

```
World (Node2D, WorldManager, y_sort)
├─ Ground (TileMapLayer, z_index −10)       แผนที่ greybox 320 × 320
├─ Signs (Node2D, y_sort)                    InfoSign ของทุกสถานที่
├─ Player (player.tscn)
│  ├─ Feet (CollisionShape2D 10 × 6 ที่เท้า)
│  ├─ Sprite (CharacterSprite)
│  ├─ Facing (Node2D หมุนตามทิศที่หัน, +Y ชี้ไปข้างหน้า)
│  │  └─ InteractionDetector (Area2D) └─ Reach (วงกลม r 10 px ห่าง 10 px ด้านหน้า)
│  └─ Camera (Camera2D zoom ×4, smoothing, physics process)
├─ WorldEdges (StaticBody2D) กำแพงล่องหน 4 ด้าน
├─ HUD · PauseMenu
```

## 5. Inspector

## 8. ข้อจำกัด (แก้ใน P2-2D)

- แผนที่ยังเป็น greybox: tile 4 แบบ ไม่มีขอบ autotile ไม่มีความสูง/หน้าผา ไม่มีต้นไม้
- อาคารเป็นบล็อกผนังเต็ม footprint ยังไม่มีประตู
- ภาพตัวละครชั่วคราว — ตัวโหลด sprite sheet ออกแบบตามรูปแบบ "Walk.png" ของ Ninja Adventure (คอลัมน์ = ทิศ, แถว = เฟรม) จะตรวจกับไฟล์จริงตอนนำเข้า

## 9. มุมมอง isometric และภาพเวกเตอร์ (อัปเดต 31 ต.ค. 2026)

ผู้ใช้เลือกสไตล์ isometric เวกเตอร์ (ดู `PIVOT_2D.md` หัวข้อ 0) ระบบการเล่นของ P1-2D ใช้ต่อทั้งหมด เพิ่ม "ภาพ" ซ้อนด้านบน

### โครงสร้างโลก
```
World (WorldManager)
├─ Sim (Node2D, ซ่อน)          การเล่นทั้งหมด บนแผนที่ top-down 16 px/tile
│  ├─ Ground (TileMapLayer)      collision: น้ำ อาคาร (ไม่แสดงผล)
│  ├─ Signs (InfoSign × n)       จุดโต้ตอบ
│  ├─ Obstacles (StaticBody2D)   วงกลมลำต้นไม้/หิน
│  ├─ Player (CharacterBody2D)
│  └─ WorldEdges
├─ View                          ภาพ isometric
│  ├─ GroundView                 พื้นเวกเตอร์ (หญ้า ถนน ลาน แปลงนา แม่น้ำ ทะเลสาบ สะพาน)
│  ├─ IslandSides                ขอบเกาะดิน 2 ด้าน
│  ├─ Objects (WorldObjects, y-sort)  อาคาร ป้าย ต้นไม้ พุ่มไม้ หิน ดอกไม้ + PlayerSprite
│  └─ Camera (Camera2D zoom 1, smoothing)
├─ HUD · PauseMenu
```
- แปลงตำแหน่ง: `WorldLayout.to_view(map_px)` = isometric (tile 128 × 64 px); `GroundView` ใช้ transform เดียวกัน พื้นที่วาดจึงตรงกับ collision เสมอ
- ปุ่มเดินอิงจอ: W = ขึ้นจอ (ตะวันตกเฉียงเหนือบนแผนที่) ผ่าน `PlayerController.input_transform`
- `WorldManager` ย้าย Sprite ของผู้เล่นออกจาก Sim ไปไว้ใน Objects และให้ Sprite กับกล้องตามตัวผู้เล่นทุกเฟรม

### ภาพ (`tools/art/iso_art.py`)
- วาดทุกชิ้นเป็น SVG ด้วยโค้ด → Chromium (Playwright) เรนเดอร์ 2 เท่า → ตัดขอบ → `assets/art/*.png`
- `assets/art/manifest.json` เก็บจุดยึด (จุดที่วัตถุแตะพื้น) ของทุกภาพ; `ArtLibrary.make_sprite(name)` สร้าง Sprite2D ที่วางตรงจุดนั้น (scale 0.5)
- มี: อาคาร 14 หลัง (ขนาดจาก footprint ในแบบแปลน, ศาลากลางมีหอนาฬิกา), บ้านหมู่บ้าน 3 แบบ, ต้นไม้ 6 แบบ (ส้ม แอปเปิล มะนาว โอ๊ก สน 2 ขนาด), พุ่มไม้ 2, หิน 2, ดอกไม้ 3, ป้าย, ลังผลไม้, โคมไฟ, ตัวละคร 4 ทิศ × 4 เฟรม
- สร้างใหม่: `python tools/art/iso_art.py` (ต้องมี Python + Pillow, Node.js + playwright) แล้วเปิด Godot ให้ import ใหม่ ภาพใน `assets/art` เปิด mipmaps ในไฟล์ `.import`
- ตั้งค่าโปรเจกต์: texture filter = Linear Mipmap, สีพื้นหลัง = ชมพูพีชอ่อน

### การวางธรรมชาติ (`WorldObjects`)
- seed คงที่ วางเฉพาะ tile หญ้าที่รอบข้างเป็นหญ้า ไม่วางบนลาน/แปลงนา ห่างป้ายและจุดเกิด
- ความหนาแน่นตามภูมิภาค (`NATURE`): ป่าทึบ ภูเขามีสนกับหิน ทุ่งหญ้ามีดอกไม้ หมู่บ้าน/ฟาร์มมีแค่ดอกไม้
- ต้นไม้และหินมีวงกลม collision ใน Sim; พุ่มไม้และดอกไม้เดินผ่านได้
- ทั้งแผนที่ ~4,800 ต้น + ~4,600 ชิ้นอื่น สร้างเสร็จ ~2 วินาที (Godot ตัดสิ่งที่อยู่นอกจอออกเองตอนวาด)

### ทดสอบ (34 ข้อ)
ข้อเดิม 25 ข้อ (ปรับให้เข้ากับมุมมองใหม่) + อาคาร 26 หลังถูกวาด · ป้ายทุกอันมีภาพ · ป่ามี ≥ 1,500 ต้น · ไม่มีต้นไม้/หินบนถนน น้ำ หรืออาคาร · Sprite ผู้เล่นอยู่ตรงตำแหน่งตัว · W เดินขึ้นจอ (ตะวันตกเฉียงเหนือ) · ขึ้นตรงในภาพ · กล้องตามผู้เล่น · ลำต้นไม้กันผู้เล่น

### ข้อจำกัด
- อาคารยังเข้าไม่ได้ ประตูเป็นภาพ; บ่อน้ำยังไม่มีภาพ
- พื้นยังไม่มีความสูง (ภูเขาเป็นพื้นราบ) — ชั้นหน้าผาเป็นงาน P2
- ถนนในหมู่บ้านต่อกับลานแบบปลายมน ยังไม่เนียน
- ทดสอบภาพบนเครื่องผมด้วยการเรนเดอร์ซอฟต์แวร์ (FPS ต่ำ ~12–26) บนการ์ดจอจริงจะเร็วกว่ามาก
